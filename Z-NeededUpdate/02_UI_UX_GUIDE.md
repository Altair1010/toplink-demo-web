# 02 — UI/UX GUIDE

> File này định hướng giao diện và trải nghiệm người dùng cho website Y Viện Toplink.

---

## 1. Tinh thần thiết kế

Website cần tạo cảm giác:

```txt
Sang trọng
Thân thiện
Tĩnh tại
Dưỡng sinh
Sạch sẽ
Đáng tin
Dễ thao tác
```

Không nên tạo cảm giác:

```txt
Quá y tế lạnh lẽo
Quá spa đại trà
Quá Trung Hoa rối mắt
Quá nhiều hiệu ứng
Quá nhiều chữ trên mobile
```

## 2. Phong cách thị giác

### 2.1. Tone màu

```txt
Đỏ trầm

Be
Nâu gỗ
```


## 3. Ngôn ngữ UI

Nên dùng ngôn ngữ gần gũi:

```txt
Hôm nay cơ thể chị/anh đang cần gì?
Để Toplink tư vấn liệu trình phù hợp
Đặt lịch trải nghiệm
Nhắn Zalo để được tư vấn
Xem đường đến Y Viện
```

Không dùng ngôn ngữ gây áp lực:

```txt
Mua ngay
Chốt đơn ngay
Cam kết khỏi
Điều trị dứt điểm
```

## 5. Mobile-first

Mobile là ưu tiên cao nhất.

### 5.1. Bottom bar mobile

```txt
Gọi ngay | Zalo | Đặt lịch | Chỉ đường
```

Yêu cầu:

```txt
Luôn hiển thị
Không che form
Icon rõ
Label ngắn
Dễ bấm bằng một tay
```

### 5.2. Header mobile

```txt
Logo
Menu icon
Nút đặt lịch nhỏ
```

Menu mobile cần nhóm rõ:

```txt
Dịch vụ
Đặt lịch
Không gian
Sản phẩm
Học viện
Hợp tác
Liên hệ
```

## 6. Trang chủ UX

### 6.1. Hero section

Hero cần có:

```txt
Headline thương hiệu
Subheadline giải thích rõ Toplink làm gì
Ảnh không gian thật
CTA Đặt lịch
CTA Nhắn Zalo
```

Headline gợi ý:

```txt
Y Viện Toplink — Dưỡng Thân, Tỉnh Thức, Cân Bằng Từ Gốc
```

Subheadline gợi ý:

```txt
Không gian chăm sóc sức khỏe kết hợp Đông y dưỡng sinh, lý liệu trị liệu và công nghệ cao, giúp cơ thể được lắng nghe, phục hồi và cân bằng.
```

### 6.2. Module chọn nhu cầu

```txt
Hôm nay cơ thể chị/anh đang cần gì?
```

Options:

```txt
Thư giãn
Ngủ ngon hơn
Cổ vai gáy
Lưng eo
Giảm căng thẳng
Phục hồi năng lượng
Dưỡng sinh định kỳ
Tư vấn liệu trình
```

Interaction:

```txt
User chọn nhu cầu
→ Hiện dịch vụ gợi ý
→ CTA đặt lịch
```

## 7. Trang dịch vụ UX

Mỗi dịch vụ cần có bố cục:

```txt
Hero dịch vụ
Vấn đề phù hợp
Ai nên dùng
Quy trình
Thời lượng
Giá/gói
FAQ
CTA
```

Nên có sidebar hoặc sticky card trên desktop:

```txt
Tên dịch vụ
Thời lượng
Giá từ
Nút đặt lịch
Nút Zalo
```

---

## 8. Trang booking UX

Luồng:

```txt
Step 1: Chọn nhu cầu
Step 2: Chọn dịch vụ / tư vấn
Step 3: Thông tin liên hệ
```

Form tối giản:

```txt
Họ tên
Số điện thoại
Nhu cầu chính
Ngày/giờ mong muốn
Ghi chú
```

Sau khi gửi:

```txt
Cảm ơn chị/anh. Toplink đã nhận yêu cầu đặt lịch và sẽ liên hệ xác nhận trong thời gian sớm nhất.
```

## 9. Dashboard UX

Dashboard phải tối giản và rõ nhiệm vụ.

### 9.1. Lễ tân

Ưu tiên màn hình:

```txt
Lịch hôm nay
Khách chờ xác nhận
Khách sắp tới giờ
Khách đã check-in
Nút tạo lịch mới
```

### 9.2. KTV

Ưu tiên màn hình:

```txt
Ca trị liệu hôm nay
Thông tin khách
Dịch vụ cần làm
Checklist
Ghi chú sau trị liệu
```

### 9.3. Quản lý

Ưu tiên màn hình:

```txt
Tổng quan hôm nay
Doanh thu
Lịch hẹn
Hiệu suất KTV
Nguồn lead
```

## 12. Accessibility

Yêu cầu:

```txt
Contrast đủ rõ
Button có label
Input có label
Error message rõ
Font size thân thiện
Điều hướng bằng keyboard ở mức cơ bản
Alt text cho ảnh
```
