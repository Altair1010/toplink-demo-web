# Decision Status

- **LOCKED** — finalized target; downstream work must follow it until intentionally superseded.
- **APPROVED** — current direction authorized for next phase; may still need system/migration lock.
- **PROPOSED** — candidate; cannot override legacy defaults or authorize mutation.
- **DEPRECATED** — historical only; must not be resurrected implicitly.

Every decision record must include:
- scope;
- evidence;
- reason;
- alternatives;
- affected surfaces;
- reversal cost;
- approver/date;
- status.
