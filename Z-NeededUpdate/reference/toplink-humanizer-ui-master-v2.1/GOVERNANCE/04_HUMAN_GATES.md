# Human Gates

## Gate A — Direction
Choose one of 3 genuinely different evidence-grounded directions.
Locks thesis, composition, photography/material character, typography behavior and motion intent.

## Gate B — System
Locks semantic tokens, component/editorial grammar, content voice, state/interaction language and motion verbs.

## Migration Gate — Mutation
Approves a concrete current→target delta before rewriting legacy tokens/components.

## Gate C — Release
Requires engineering verify + browser/task/state/a11y/visual review + Humanizer rubric + no unresolved P0/P1 defect.

Gate rule: **approve consequences, not harmless exploration**. Agents may research, wireframe, critique and prototype locally before a gate unless mutation/external action is involved.
