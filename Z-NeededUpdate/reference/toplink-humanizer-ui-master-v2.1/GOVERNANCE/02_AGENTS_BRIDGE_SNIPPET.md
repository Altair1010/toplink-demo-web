```md
## Humanizer UI Program

The Humanizer package defines a Target Design Truth for approved redesign work.

- Existing engineering, accessibility, security, static-export, basePath, reduced-motion,
  token-hygiene and verification constraints in this AGENTS.md remain mandatory.
- `tokens.css` and actual source remain Runtime Truth for what the site currently does.
- A Humanizer Decision marked `LOCKED` may supersede legacy DESIGN.md decisions only within
  its declared design scope (palette, typography, composition, imagery, visual hierarchy,
  motion grammar, decorative language, component appearance).
- Target decisions do not authorize source mutation by themselves. An approved Migration Record
  must map target decisions to code/token deltas before implementation.
- Architecture-level changes require separate explicit approval.
<!-- HUMANIZER:END -->
```
