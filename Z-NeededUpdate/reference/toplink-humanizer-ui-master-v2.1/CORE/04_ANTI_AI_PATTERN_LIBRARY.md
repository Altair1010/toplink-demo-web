# Anti-AI Pattern Library

## Generic visual probability — reject by default
- repeated 3-card grids without information reason;
- decorative bento as default composition;
- random glow/gradient for “premium”;
- pill-everything;
- icon-per-paragraph;
- identical reveal animation on every section;
- fake editorial numbering where content is not sequential.

Anthropic's official `frontend-design` skill independently warns that current AI design clusters around a few repeated visual defaults and that structure should encode real information rather than decoration.  
**Nguồn:** [Anthropic frontend-design skill](https://github.com/anthropics/skills/blob/3b3fad96af16a10759d930941b4520ba0c40edae/skills/frontend-design/SKILL.md)

## Generic wellness language
Reject unless immediately evidenced:
- “cân bằng toàn diện”;
- “đánh thức năng lượng”;
- “hành trình chữa lành”;
- “nâng tầm sức khỏe”;
- “tận tâm chuyên nghiệp”.

## Fake humanity — hard fail
- invented testimonial;
- invented practitioner quote;
- synthetic staff portrait presented as real;
- fabricated statistic;
- fake scarcity/activity;
- health certainty added merely to sound expert.

## Over-humanization — also fail
- deliberate misalignment for handmade effect;
- low contrast for “heritage” mood;
- illegible type;
- animation that delays task completion.

Navigability, aesthetics and comprehensibility are themselves health-information quality cues; Humanizer must not trade them away.  
**Nguồn:** [JMIR 2022 meta-analysis](https://www.jmir.org/2022/4/e36463/)
