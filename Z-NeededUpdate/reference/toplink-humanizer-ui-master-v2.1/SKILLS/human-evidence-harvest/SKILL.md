# Human Evidence Harvest

## Goal
Replace generic brand inference with inspectable evidence.

## Evidence classes
- E1 People
- E2 Hands/craft
- E3 Place
- E4 Materials
- E5 Micro-stories
- E6 Process
- E7 Real customer/staff language
- E8 Trust/provenance

## Workflow
1. Inspect supplied files/media/content before asking for more.
2. Create/update Human Evidence Inventory.
3. Tag every item: source, owner/person, consent/status, claim supported, potential page use.
4. Score specificity / reality / usefulness 0–2.
5. Produce Missing Evidence list.

## Hard rules
- never invent quotes/testimonials/credentials/metrics;
- do not use stock/synthetic image as “real evidence”;
- distinguish observed fact from interpretation;
- do not start art direction if critical evidence gaps would materially change it.
