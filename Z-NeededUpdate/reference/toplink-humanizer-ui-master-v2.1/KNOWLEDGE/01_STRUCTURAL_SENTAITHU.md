# Structural Evidence — Sen Tài Thu

## Role

Sen Tài Thu is a **structural evidence source**, not a visual template.

The supplied DNA characterizes the site as selling an experience/world and highlights the relationship between Space, Services and People before deeper service discovery.

## What Toplink may learn

`brand orientation → physical/place proof → method/service → people proof → therapy discovery → booking`

## What Toplink must not transfer automatically

- palette;
- fonts;
- exact section geometry;
- exact copy;
- plugin/widget motion presets;
- decorative identity.

## Structural test

For each borrowed pattern ask:
1. What user question does this ordering answer?
2. What evidence makes it credible for Toplink?
3. Does it survive without Sen Tài Thu's brand identity?
4. If yes, adapt the relationship; if no, reject.
