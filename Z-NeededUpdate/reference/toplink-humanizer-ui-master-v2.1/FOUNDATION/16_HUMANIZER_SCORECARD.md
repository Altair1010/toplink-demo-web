# Humanizer Scorecard

Score each dimension 0–5.

| Dimension | 0 | 5 |
|---|---|---|
| User reality | assumed persona | observed needs/context |
| Human evidence | stock/generic | real Toplink evidence |
| Specificity | interchangeable | uniquely Toplink |
| Professional voice | vague wellness | domain-specific + understandable |
| Narrative | component list | intentional attention sequence |
| Visual materiality | generic theme | translated from physical brand |
| Interaction consequence | system jargon | next human/system action clear |
| Trust | claims | provenance + identity + limits |
| Motion meaning | decoration | semantic/state/narrative |
| Accessibility | afterthought | verified baseline |
| State completeness | happy path | critical edge states |
| Commercial clarity | vague CTA | clear task/next step |

## Interpretation

- **0–24**: AI/template dominant
- **25–39**: branded but generic
- **40–49**: credible humanized direction
- **50–60**: strong candidate for production review

This scorecard is a project heuristic, not a validated psychometric instrument.

## Hard fail overrides

Regardless of score:
- fabricated evidence;
- inaccessible critical path;
- misleading health certainty;
- CTA consequence unclear;
- fake testimonial/metric;
- broken mobile task;
- motion without reduced-motion fallback.
