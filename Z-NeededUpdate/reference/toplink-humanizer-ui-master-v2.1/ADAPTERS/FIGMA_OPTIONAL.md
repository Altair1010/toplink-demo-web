# Figma MCP — Optional Adapter

Figma MCP can provide design context such as components/variables/layout information, and Figma recommends structured components, semantic naming, variables and Auto Layout to reduce agent guessing.  
**Nguồn:** [Figma MCP](https://developers.figma.com/docs/figma-mcp-server/)  
**Nguồn:** [Figma structure guidance](https://developers.figma.com/docs/figma-mcp-server/structure-figma-file/)

## Enable only if
- the user wants Figma as the visual approval surface;
- designers will annotate/recompose there;
- there is a real design↔code handoff need.

## Do not enable merely because “professional UI uses Figma”.
Humanizer can run code-first with screenshots/browser gates.
