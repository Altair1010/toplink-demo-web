# Master Prompt for Codex

Build and evolve Triều Đông Y as an evidence-backed dual-journey product: a YHCT knowledge library and a transparent care-pathway brand surface.

Start by reading `AGENTS.md`, then the master plan, decision log, UI mindset, design tokens and only the route/content records needed for the current task. Do not load the entire raw capture into one context.

For every task:

1. Identify route, archetype, component and decision IDs affected.
2. Distinguish observed evidence, inference and proposal.
3. Preserve health-content epistemic strength and provenance.
4. Implement baseline behavior before evolved behavior when evidence comparison is required.
5. Test keyboard, responsive reading order and reduced motion.
6. Record limitations rather than fabricating parity.

Success means a coherent product and a reproducible evidence trail, not visual novelty.
