# Triều Đông Y Web DNA

An evidence-backed reconstruction and evolution package for `trieudongy.vn`.

The repository contains:

- 634 rendered route captures and normalized content records;
- design, asset, site, composition, interaction and motion graphs;
- a source-aware baseline renderer;
- an evolved dual-journey product prototype;
- UI mindset, decision records, QA reports and a Codex operating contract.

Start with `docs/web-dna/00_MANIFEST.md`, `AGENTS.md` and `MASTER_PROMPT.md`. Run `npm test` for the release gate. Raw evidence is immutable; regenerate derived artifacts with `node scripts/build-web-dna.mjs`.
