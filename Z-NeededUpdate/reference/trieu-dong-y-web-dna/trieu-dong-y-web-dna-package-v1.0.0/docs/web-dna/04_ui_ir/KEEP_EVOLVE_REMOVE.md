# Keep / Evolve / Remove

| Area | Keep | Evolve | Remove |
|---|---|---|---|
| Identity | Paper, green, vermilion, YHCT vocabulary | More systematic semantic tokens | Using every brand color at equal emphasis |
| Content | Full taxonomy and long-form corpus | Entity relationships and source traces | Flat archives as the only discovery model |
| Homepage | Treatment methods and knowledge collections | One promise with two ordered entry paths | “Everything is primary” composition |
| Navigation | Recognizable content families | Task-based top level plus deep knowledge index | Long undifferentiated dropdown lists |
| Articles | Rich headings and related material | Reading rail, facts, provenance, safety state | Intrusive contact prompts inside reading flow |
| Lookup | Symptom-to-acupoint educational concept | Explicit boundaries and related-knowledge handoff | Diagnostic wording or personalized prescription |
| Motion | Fast hover/press feedback | Consistent 120/200/250ms token system | Indefinite decorative animation |
| Care | Visible methods and contact options | Process, suitability and expectation framing | Absolute outcome claims |
