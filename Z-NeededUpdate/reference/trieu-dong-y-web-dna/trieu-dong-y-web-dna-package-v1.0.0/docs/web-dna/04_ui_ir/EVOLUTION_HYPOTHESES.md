| H-01 | A dual-entry hero reduces orientation time. | Time to first valid action; backtracking. | No improvement or more backtracking. |
| H-02 | Entity-based exploration improves content discovery. | Refinement success; related-content continuation. | Discovery does not improve or confusion rises. |
