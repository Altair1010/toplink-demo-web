# Triều Đông Y Web DNA — Package Manifest

**Package version:** 1.0.0-release-candidate  
**Source origin:** https://trieudongy.vn/  
**Census date:** 2026-08-13  
**Current gate:** G5 — Release verification

## Purpose

This package is an evidence-backed representation of the source website's structure, visual language, interaction grammar, motion behavior, and content topology. It is designed for Codex to reconstruct a faithful baseline first, then generate controlled UI transformations without losing the source site's identity.

## Current contents

- `01_governance/`: scope, permissions, decisions, source lock, gate reports.
- `02_evidence/`: verification register and later raw/derived evidence envelopes.
- `03_inventory/`: route census, archetypes, priorities, and capture states.
- `04_ui_ir/`: schemas for the intermediate UI representation.
- `05_graphs/`: site, asset, composition, interaction and motion graphs.
- `06_qa/`: baseline, evolved and release verification reports.
- `data/`: normalized full corpus, render projection and search projection.
- `tools/`: authorized motion-capture engine supplied by the user.
- `app/`: review dashboard for human gates.

## Gate discipline

No downstream capture or transformation stage may silently convert an unknown into a fact. Every derived assertion must point to raw evidence, a reproducible transform, or an explicitly recorded inference.
