# H7 Authority Boundary for Toplink V1

**Status:** LOCKED by D-002, D-003, D-004 and `SOURCE-OF-TRUTH.md`.

The H7 website is a technical salvage source and historical comparison artifact. It does not define
future:

- visual hierarchy;
- page morphology;
- section order;
- color palette;
- typography;
- motion language;
- copy;
- navigation architecture;
- information architecture;
- conversion model.

An H7 file or component may survive only when its engineering value is independently demonstrated
against the V1 product, accessibility, architecture and design contracts. Existing runtime presence,
visual polish or prior verification is not sufficient design authority.

This boundary applies to later agents, new chats, PR reviews and rebuild decisions. `DESIGN.md`,
`tokens.css`, `skins.css`, current route allowlists and current section composition remain accurate
historical runtime sources, but they are deprecated as V1 target-design sources.

P0 classification does not authorize mutation. `DELETE-CANDIDATE` means inventory only.
