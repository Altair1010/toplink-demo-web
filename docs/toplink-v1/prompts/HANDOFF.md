# Actor Handoff Template

Use this instead of copying long chat history.

```text
PHASE:
BRANCH:
HEAD:
COMPLETED:
FILES CHANGED:
TESTS / BROWSER CHECKS ACTUALLY RUN:
OPEN P0/P1:
DECISIONS CHANGED:
FACTS STILL PENDING:
NEXT ACTOR:
ONE NEXT ACTION:
HUMAN GATE REQUIRED?:
```

The receiver must verify GitHub/worktree state rather than trusting the handoff blindly.
