# Art Direction / Commercial Readiness Rubric

Score each representative surface 0–5.

| Dimension | Weight |
|---|---:|
| Brand specificity | 15% |
| Structural originality / non-template quality | 12% |
| Information hierarchy | 10% |
| Audience readability & comfort | 10% |
| Typography craft | 8% |
| Color/material/ornament coherence | 8% |
| Image direction | 7% |
| Motion meaning/craft | 7% |
| Service/content discoverability | 8% |
| Trust/evidence/boundary communication | 8% |
| Conversion clarity without pressure | 7% |

## Minimum release expectations

- no dimension below 3/5;
- weighted score >= 4/5;
- brand specificity, readability and trust each >= 4/5;
- no unresolved fatal accessibility/health-truth issue.

## Review method

Use at least one human/blind comparison or external critique that is not the same model that authored the surface. Automated detector output cannot substitute for this judgment.
