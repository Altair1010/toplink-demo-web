# Authorized Reference Policy

## Sen Tài Thu

The user states they have authorization to clone the source website, but the V1 project intentionally limits reuse to:

- structure;
- layout/composition;
- UI patterns;
- UX behavior;
- responsive behavior;
- motion/interaction choreography.

### Do not ship

- Sen copy/text;
- Sen photos/video;
- Sen icons/brand marks;
- prices;
- health/service claims;
- testimonials/customer data;
- metadata or SEO copy;
- copied JavaScript/CSS as an opaque dependency.

### Preferred technique

Reverse-engineer behavior into a Toplink reference genome:

`observe → state-map → measure → abstract → judge ADOPT/ADAPT/REJECT → reimplement in Toplink system`

This yields a reusable design grammar instead of a fragile clone.

## Brand dossier

The uploaded Toplink dossier may be used directly as project source material. Its provisional colors/visual notes are exploration inputs only until the extraction phase locks production tokens.
