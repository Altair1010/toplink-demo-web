# P9 Operations Prerequisites

P9 requires an approved public domain/HTTPS host, persistent WordPress database/uploads, secret distribution, admin hardening, backup/restore drill, monitoring, rollback, webhook topology and real approved contact/content/media inputs. Search Console/DNS/indexing remain post-host actions. Single instance may retain bounded in-process replay after review; multi-instance/serverless must add shared replay/deduplication. Webhook failure must remain non-blocking with TTL recovery and operational monitoring. Nothing in this document authorizes deployment.
