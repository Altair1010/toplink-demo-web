# toplink-headless-commercial-redesign-master v1.0.0

Planning/orchestration package for the Y Viện Toplink full redesign and headless WordPress migration.

Start with `START-HERE.md`.

This package intentionally contains **plans, contracts, prompts and user-supplied source material**, not copies of the Hallmark/Impeccable repositories. Upstream revisions are pinned in `sources/UPSTREAM-PINS.md` and can be fetched locally with the non-mutating helper scripts.

The helper scripts do not commit, push, deploy, change DNS or change repository visibility.
