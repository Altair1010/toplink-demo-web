# Toplink Brand Extraction Phase

## Source condition

The user has a preliminary brand dossier but **no final font, pattern or palette system**. Therefore the dossier is a directional source, not finished Visual Identity Guidelines.

## Source concepts to preserve

- Y Viện Dưỡng Thân – Tỉnh Thức
- Thân khỏe – Tâm an – Trí sáng
- caregiver / sage / guide personality
- warm, calm, knowledgeable, transparent voice
- Tân Trung Hoa
- Tĩnh → Thông → Dưỡng → Tỉnh
- Lý liệu / Dược liệu / Dưỡng liệu conceptual system
- non-fear-selling health communication
- respect for privacy, consent and limits

## Extraction workflow

### Step 1 — semantic inventory

Extract words, metaphors, ritual moments, material associations and service behaviors from the dossier.

### Step 2 — provisional visual families

Generate several visual families without selecting a final palette/font. Each family must define:

- tonal range;
- color role hierarchy;
- surface/material behavior;
- type character;
- ornament grammar;
- image crop/lighting;
- motion character.

### Step 3 — browser comps

Test the same representative content using all candidate families at desktop and mobile.

### Step 4 — audience stress test

Check readability/comfort for:

- office users 28–55;
- older visitors;
- caregivers;
- privacy-sensitive women;
- remote knowledge readers.

### Step 5 — human gate

User chooses or combines one direction.

### Step 6 — lock production tokens

Only now write production tokens and `DESIGN.md`.

## Anti-literalism rule

“Đông y cung đình” must be expressed as system behavior/material hierarchy, not merely red + gold + Chinese border.
