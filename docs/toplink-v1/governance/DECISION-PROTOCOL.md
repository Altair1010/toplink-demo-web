# Decision Protocol

Use compact ADRs only for decisions that affect multiple future phases.

## Status

- `PROPOSED`
- `APPROVED`
- `LOCKED`
- `DEPRECATED`

## Create an ADR when

- routing/IA changes;
- CMS data model changes;
- dependency/runtime changes;
- design direction changes;
- production hosting changes;
- privacy/analytics behavior changes;
- a previously locked requirement is intentionally replaced.

Do not create ADRs for ordinary CSS tweaks.

## Template

```text
ID / Date / Status
Context
Decision
Why
Consequences
Replaces (if any)
Evidence
```
