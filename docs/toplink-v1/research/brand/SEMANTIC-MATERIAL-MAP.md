## Provisional dimension ranges

- **Tonal range:** warm dark anchors plus highly readable light information fields; exact colors open.
- **Color roles:** anchor / surface / text / semantic state / ceremonial accent; exact values open.
- **Surface behavior:** matte, tactile suggestion, restrained translucency; no literal faux-material UI.
- **Type character:** humane editorial authority plus highly legible functional text; font names open.
- **Ornament:** structural punctuation, low repetition, never a universal border system.
- **Imagery:** authorized human/place detail, warm controlled light, dignity-preserving crop.
- **Motion:** state explanation and orientation first; low amplitude; no production timings locked.
