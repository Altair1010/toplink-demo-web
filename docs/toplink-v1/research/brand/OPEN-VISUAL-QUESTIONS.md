# Open Visual-Identity Questions

Only questions that can change a later decision are included. Count: **10**.

| Question                                                                           | Why it matters                                                               | When it must be resolved                  | Evidence that would resolve it                                                          |
| ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- | ----------------------------------------- | --------------------------------------------------------------------------------------- |
| What is the authoritative logo set and usage geometry?                             | Identity scale/clear-space and symbol behavior cannot be inferred from prose | Before P3 direction comp finalization     | Original vector files plus approved usage rules                                         |
| Which color roles survive real logo/material/contrast tests?                       | Dossier hex values are provisional and may fail digital accessibility        | During P3 before token lock               | Logo originals, physical material samples/photos, WCAG contrast tests and browser comps |
| What type character balances Vietnamese readability and Tân Trung Hoa depth?       | Font choice affects older users, brand authority and performance             | P3 comparison gate                        | Licensed candidates tested with Vietnamese diacritics at 375/1440 and zoom              |
| Is there an authentic Toplink ornament/pattern source?                             | Invented motifs would create fake heritage                                   | Before any production pattern is approved | Authorized architectural/brand source and provenance review                             |
| How much ornament can each surface tolerate?                                       | Density can shift the brand from controlled to theatrical                    | P3 candidate comparison                   | Same-content comps scored across five audiences                                         |
| What actual place/material palette exists at Toplink?                              | Digital material cues should not misrepresent a non-existent facility        | Before production space/brand imagery     | Authorized current facility photography and material specification                      |
| What real photography is authorized and consented?                                 | Production cannot impersonate people, premises or outcomes                   | Before P4 production image system         | Asset register with owner, consent, subject, location and allowed use                   |
| Which crop rules protect dignity during care scenes?                               | Wellness imagery can become voyeuristic or imply medical evidence            | P3 image-direction gate                   | Consented test set reviewed for privacy and health-claim implications                   |
| What motion intensity is comfortable across all five audiences?                    | Strong procession/ambient motion may undermine calm and accessibility        | P3 motion direction gate                  | Prototype comparison with reduced-motion replacement and audience review                |
| How should “Tĩnh → Thông → Dưỡng → Tỉnh” appear without becoming a forced sitemap? | It is a powerful brand narrative but not yet product IA                      | After P2 IA, during P3 synthesis          | Approved page jobs/content sequence plus candidate morphology tests                     |
