## Composition grammar worth carrying forward

- Use page morphology that matches the job rather than one universal card grid.
- Let one dominant section own each viewport; avoid equal-weight module piles.
- Pair recognition media with explanatory copy, then collapse to a deliberate mobile reading order.
- Keep conversion surfaces available but subordinate to understanding and trust.
- Use progressive disclosure for large operational sets; do not expose a full directory wall upfront.
