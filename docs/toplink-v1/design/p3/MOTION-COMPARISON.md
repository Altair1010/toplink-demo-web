# Motion Comparison

All behavior is provisional P3 comparison code using CSS/native interaction only. No motion engine was installed.

## A — Threshold

- **Purpose:** reveal a calm threshold after the identity and reading promise are already legible.
- **Trigger:** initial page entry.
- **From → to:** clipped material arch, translated down → settled abstract threshold.
- **Duration/easing:** 760 ms; restrained deceleration (`cubic-bezier(0.16, 1, 0.3, 1)`).
- **Mobile:** smaller arch remains below the main reading block; no scroll dependency.
- **Reduced motion:** animation removed; final state is present immediately.
- **Fit:** arrival and restraint support Tĩnh without turning every section into a reveal.

## B — Focus

- **Purpose:** let the reader focus one Tĩnh/Thông/Dưỡng/Tỉnh explanation at a time.
- **Trigger:** explicit button selection.
- **From → to:** one indexed explanation visible → another explanation visible; `aria-pressed` follows state.
- **Duration/easing:** immediate native state change; only hover/focus color feedback uses 180 ms ease.
- **Mobile:** four large targets become a two-column lens rail; content follows below.
- **Reduced motion:** state remains fully usable with no spatial animation or motion dependency.
- **Fit:** the motion is evidence-oriented disclosure, matching the living-apothecary mechanism.

## C — Release

- **Purpose:** introduce a processional frame, then release the reader into sequential chapters.
- **Trigger:** initial page entry; later navigation is native anchor movement.
- **From → to:** gateway clipped/offset → stable chamber frame.
- **Duration/easing:** 680 ms; controlled deceleration, no bounce.
- **Mobile:** frame scales to the viewport; stage sequence remains linear.
- **Reduced motion:** gateway animation removed and smooth scrolling disabled.
- **Fit:** a single ceremonial release supports procession without scroll hijacking.

## Boundary

No pulsing CTA, continuous ambient spectacle, scroll hijack, bounce, or every-section fade-up exists. P3B must re-evaluate the selected direction; these are not production motion tokens.
