# Audience Stress Test

Heuristic same-agent review only; this is **not** real-user testing.

| Segment                           | A — Quiet Meridian                                                              | B — Living Apothecary                                                                                   | C — Contemporary Procession                                                                   |
| --------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Busy Hanoi adults                 | Calm hierarchy supports scanning; long quiet passages can feel slow             | Indexed workbench offers fastest comparison and service discovery                                       | Strong chapters orient well, but the long procession asks more scrolling                      |
| Middle-aged / older               | Largest display/body comfort and low density; decorative spine is non-essential | Labels are explicit and touch targets are generous; denser evidence surface needs careful type sizing   | Clear stage order and high contrast; large theatrical headlines must not displace explanation |
| Parent caregivers                 | Limitation/trust chapter is prominent without pressure                          | Relationship between need, evidence and next step is clearest                                           | Process is memorable, but chamber metaphor must stay plain-language underneath                |
| Proactive/privacy-sensitive women | Quiet, non-clinical posture supports privacy                                    | Transparent records and explicit limitations build control; specimen metaphor must not objectify people | Dignified world, though stronger ceremony risks authority theatre if overdone                 |
| Nationwide knowledge readers      | Reading-led cadence supports a no-contact completion                            | Knowledge index and contextual relationships are strongest                                              | Knowledge hall is distinct, but homepage vertical length is highest                           |

## Shared checks

- One H1 per tested surface; semantic sections and headings preserved.
- Mobile has an explicit native `details` menu with 44 px minimum target.
- No essential hover-only information; B state uses buttons and `aria-pressed`.
- Required viewports have no horizontal overflow.
- Contact destinations remain non-actionable while facts are pending.
- Motion has a usable reduced-motion counterpart.
