# Direction C Asset Integration Contract

**Rule:** missing asset evidence does not block structural implementation and must never be invented.
All four inputs are `PENDING`. P4 prepares slots; publication remains fail-closed under P2 contracts.

## 1. Authoritative logo set and geometry

- **Current status:** PENDING; P3B uses plain text `Y VIỆN TOPLINK` as a scaffold.
- **Why it matters:** wordmark proportions, clearspace, minimum size and identity accent calibration.
- **Affected surfaces:** header identity, footer, favicon/app icons, social/OG templates, possible seal.
- **Temporary behavior:** accessible text identity; no invented mark, crest or H7/Sen substitute.
- **Insertion:** register original vector/source and rights → verify variants/geometry → define clearspace,
  minimum size and contrast → replace only the `logo.*` slot → browser-check 375/1440 and metadata.
- **Stable after insertion:** header height contract, navigation hierarchy, page morphology and type scale.
- **May update:** logo rendering, clearspace, identity accent nuance and favicon/OG assets.

## 2. Authentic ornament/pattern source

- **Current status:** PENDING; only structural rules/inset frames are permitted.
- **Why it matters:** provenance and specificity prevent generic or culturally literal decoration.
- **Affected surfaces:** gateway/threshold ornament slot and selected editorial dividers.
- **Temporary behavior:** CSS rules and joinery geometry; no lattice, seal or floral imitation.
- **Insertion:** document source/rights/meaning → simplify into scalable SVG/CSS asset → test at one
  gateway and one threshold → verify contrast/reading interference → register `ornament.asset`.
- **Stable after insertion:** ornament scarcity, one-family-per-chapter rule, spacing and hierarchy.
- **May update:** motif geometry, stroke density and asset-specific responsive crop.

## 3. Actual Toplink place/material evidence

- **Current status:** PENDING; prototype material planes are explicitly abstract.
- **Why it matters:** validates real wood/metal/textile/color nuance and the `/khong-gian` page job.
- **Affected surfaces:** material tokens, place evidence chapters and space route publication.
- **Temporary behavior:** conditional abstract plane; never captioned as Toplink premises.
- **Insertion:** collect dated/source-located evidence → verify it represents the actual place → derive
  bounded material nuances → retest identity defaults and contrast → publish only approved records.
- **Stable after insertion:** reading neutrals, morphology, density, evidence-first page order.
- **May update:** `identity.anchor`, `identity.metal`, `material.plane` and real-space crop rules.

## 4. Authorized / consented photography

- **Current status:** PENDING; no people, staff, customer, procedure or facility claim is visualized.
- **Why it matters:** authenticity, dignity, privacy and truthful media roles.
- **Affected surfaces:** homepage atmosphere, service explanation, editorial stories and space evidence.
- **Temporary behavior:** omit image modules or use clearly abstract/generic atmosphere where allowed.
- **Insertion:** create Media record → record provenance, license/consent, identity class, role, alt text
  and publishability → approve crop variants → insert through `media.*` slot → verify privacy context.
- **Stable after insertion:** content order, page job, trust/caution placement and reading measure.
- **May update:** crop focal point, aspect ratio within allowed slot, caption and image treatment.

## Override governance

An asset insertion is not permission to reopen Direction C. Any proposed change to morphology,
hierarchy, type scale, motion family or commercial path requires a new explicit decision. Asset
changes must preserve WCAG contrast and P2 status/authorization rules.
