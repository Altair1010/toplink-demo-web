# Audience Journey Map

**Authority:** `sources/AUDIENCE-PROFILE.md` and D-046.  
**Purpose:** map needs to information and safe next steps without diagnosis or forced conversion.

## 1. Người bận rộn ở Hà Nội, khoảng 28–55

| Contract item              | P2 definition                                                                                       |
| -------------------------- | --------------------------------------------------------------------------------------------------- |
| Primary need               | Understand a regular, easy-to-follow care option without sales pressure.                            |
| Concern / friction         | Limited attention; fear of health selling; no diagnosis funnel.                                     |
| Information required       | Toplink role; service families; bounded fit; process; limits/cautions; approved organization facts. |
| Trust required             | Plain explanation, no pressure, no invented outcomes, visible boundaries.                           |
| Likely entry surface       | Home, service index, relevant knowledge or search.                                                  |
| Useful content             | Concise service summaries, evergreen explanations, FAQs and related knowledge.                      |
| Relevant service discovery | Need-family navigation in non-diagnostic language, then approved detail.                            |
| Contact trigger            | After understanding fit/process/limits and wanting human clarification.                             |
| Safe next step             | Continue learning, inspect a service, or use one verified external channel.                         |

| Contract item              | P2 definition                                                                                |

| Contract item              | P2 definition                                                                                         |

## 5. Người quan tâm dưỡng sinh toàn quốc

| Primary need               | Learn safe dưỡng sinh knowledge and habits usable away from a facility.                   |

| Useful content             | Long-form education, summaries, related topics and escalation where relevant.             |
| Relevant service discovery | Optional contextual relation only when it helps understanding.                            |
| Contact trigger            | Not required; available only if the reader independently wants clarification.             |
| Safe next step             | **DONE:** learn → understand → apply safe bounded knowledge; optionally keep learning.    |

## Cross-journey rules

- Never map symptom → diagnosis → treatment.
- Do not infer individual suitability from browsing behavior.
- Contact is optional and cannot block knowledge, cautions or organization facts.
- A service relation must explain semantic relevance; it is not an automatic conversion link.
- If critical evidence is pending, omit the field or keep the page unpublished.
