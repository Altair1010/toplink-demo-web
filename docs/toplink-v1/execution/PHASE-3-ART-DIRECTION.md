# Phase Card P3 — Art Direction

## Direction sprint

1. Use same representative content for all candidate directions.
2. Generate three materially different compositions/worlds.
3. Use Hallmark to ensure structural difference is real.
4. Use Impeccable to keep product/UX/craft constraints intact.
5. Build browser comps rather than moodboard-only decisions.
6. Include desktop + mobile and at least one motion storyboard per direction.
7. Score against audience, brand specificity, readability, commercial usefulness, extensibility and performance.
8. User selects one direction.

## After selection

Compile final:

- `DESIGN.md`
- tokens
- type system
- color system
- image direction
- ornament rules
- motion grammar
- page morphology library
- structural memory
- Toplink anti-pattern lint list

## Exit

No broad frontend implementation without a selected browser-tested direction.
