### Collision questions

| Question                                                           | Finding                                                                                                                                                                    |
| ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| If Triều disappears, does the system still emerge?                 | The behavioral system does. The exact H3-B visual/brand spine does not have enough independent Toplink evidence to be relocked.                                            |
| Is “record” functional or identity?                                | Mixed. Exact editable review/status is functional; making “record” the universal noun turns it into identity.                                                              |
| Does paper/ink come from readability or archive?                   | Readability justifies contrast/measure bounds, but the paper/ink + vermilion + ruled-record combination functions as archive identity. H4 did not isolate those variables. |
| Does Proof Index solve trust?                                      | Its render-or-omit and contextual proof contract does. The “index” name can still push implementation toward metadata-first presentation.                                  |
| Is metadata user-needed?                                           | Recipient, scope, updated/reviewer/source class can be useful. ED codes, status badges and dense provenance are operational, not visitor identity.                         |
| Does “Hồ Sơ Sống” create unwanted meaning?                         | Yes: it can imply a medical record, administrative dossier or a translated living archive.                                                                                 |
| Can the same system use a Toplink-specific non-archive expression? | Probably, but it must be designed and blind-compared in the reopened H3 visual subtree rather than asserted by renaming.                                                   |

### Classification

`MATERIAL CONTAMINATION`

The R4 applies to the H3-B visual/brand spine and its H4/H5 visual descendants. It does not reopen H0–H2 or discard evidence, scope and consequence contracts.

H4's statement that it rejected archive cosplay is insufficient because its reading measure, material field, ruled rows and record/provenance grammar still form the same recognizable system. Renaming nouns cannot validate independence.

### Corrective rule

Keep:

- accountability;
- evidence before claim;
- scope/limit;
- editable user language;
- truthful action state and recovery;
- matte high-contrast reading behavior.

Strip/reframe:

- `Hồ Sơ Sống` as the active target codename;
- archive theatre and medical-record implication;
- paper-as-archive symbolism;
- record/register/index/receipt as default component nouns;
- provenance/metadata as visible authority decoration.

**Dòng Chăm Sóc Rõ Ràng** is only a neutral working proposal for the reopened subtree, not a locked or distinctive Toplink thesis. Historical H3/H5 records retain “Hồ Sơ Sống” as provenance.
