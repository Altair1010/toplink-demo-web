## VX-02 genealogy — rebuilt B

- uncertainty and recovery;

### Contaminated elements removed

- public record/index/register/receipt naming system;
- provenance density and visible metadata as brand grammar;

### New independent expression

The replacement is `Nhịp Hỏi — Đáp Rõ`: ordinary-language question → bounded answer → real evidence
at the trust point → scope → consequence-dominant action. It requires neither reference visual
system and remains legible in grayscale with one sans system and minimal motion.

This does not rename and preserve the failed system. It replaces its visual thesis while retaining
the independently justified jobs.
