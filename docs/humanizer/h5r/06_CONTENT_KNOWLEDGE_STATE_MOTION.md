# 06 — Content, Knowledge, State and Motion

## Content voice relock

`Toplink voice = question-first natural Vietnamese + professional specificity + calm responsibility + clear limits + visible consequence.`

Use direct second-person acknowledgment and explain domain terms immediately. Prefer a verified
observation over a claim. State uncertainty before inviting action. Reject bureaucratic micro-labels,
medical-authority theatre, generic wellness promises, urgency and invented operational certainty.

## Bounded knowledge amendment

**Verdict: BOUNDED.** J-06 and the H4R-C learning branch justify one shared care/learning relation:

```text
VISITOR
  |-- "Tôi muốn được định hướng" --> guided care path
  `-- "Tôi muốn hiểu thêm" ------> reviewed explanation
                                         |
                                         `--> safe return / related next question
```

The amendment locks three responsibilities, not a large portal:

1. **Knowledge Entry:** a bounded set of reviewed practical questions/terms.
2. **Knowledge Detail:** familiar question → plain explanation → scope/limit → source/review
   operation → safe continuation.
3. **Care ↔ Knowledge Bridge:** contextual links in both directions without diagnosis, personal
   recommendation or shared medical ontology.

Source/review fields are content operations. They appear publicly only when useful to judge a claim;
they never become archive badges or a second visual system. Triều supports this relationship only;
its taxonomy breadth, visual identity and claims are not imported.

## State and consequence retained

Retained from `DEC-H5-GB-01`: editable/removable orientation; no automatic service match; IDLE,
ORIENTED, INPUT/REVIEW, local-only/unsent, ERROR/FAILURE, RETRY, UNCERTAIN and real human handoff
when operationally verified. A real pending/sent/confirmed state remains unavailable until actual
transport, recipient, privacy/security, recovery and end-to-end evidence exist.

Order is locked:

`ACTUAL CONSEQUENCE → CURRENT STATE → EDIT / RECOVER / REMAIN UNCERTAIN → ACTION`.

## Motion relock

- **KHAI:** an answer or possibility becomes available without delaying content.
- **DẪN:** attention moves to the next meaningful relation.
- **TỤ:** selected visitor language gathers into a clear editable summary.
- **AN:** state or consequence settles without celebration.

Motion remains sparse, local and semantic. Advanced choreography remains GSAP-only; simple state
feedback may use CSS. Reduced motion exposes identical information immediately. No archive
metaphor, progress theatre, shimmer, parallax, pulse or new engine.

## Responsive and accessibility relock

Retain 375/768/1280/1440, 200%-equivalent reflow, Vietnamese wrapping, keyboard, visible focus,
semantic order, touch targets, contrast and reduced-motion parity. Add one explicit invariant:
mobile arrival, boundary and consequence exchanges remain structurally differentiated rather than
collapsing into the same heading/paragraph/button stack.

## Security/privacy and anti-AI

Retain data minimization, explicit recipient/consequence, no false submission and fail-closed
publication. Reject repeated cards, chat UI, stock/synthetic people as evidence, fake
testimonials/metrics/live state, low-contrast heritage styling, ornamental metadata, medical
certainty and decorative motion.
