# 02 — Corrected Target Design Grammar

**Status:** `PROPOSED FOR GATE B-R`

## System thesis

**Nhịp Hỏi — Đáp Rõ giúp người đọc bắt đầu từ điều mình đang quan tâm, nhận một câu trả lời vừa đủ,
hiểu rõ giới hạn và hệ quả, rồi tự chọn bước tiếp theo.**

Toplink behaves as a sequence of clear human questions and bounded, responsible answers. Identity
comes from the reliability of that relation—not archive, clinical authority, prestige or color.

## Corrected grammar

| Question                                | Locked answer                                                                                                                                                                 |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A. Visual thesis                        | Question → bounded answer → evidence when approved → scope/consequence → truthful next step.                                                                                  |
| B. What relates sections?               | One ordinary-language question, one accountable response, consistent reading/focus order and visible limits.                                                                  |
| C. What varies?                         | Scale, alignment, width, density, evidence interruption, surface contrast, action gravity and horizontal/vertical relation vary by job.                                       |
| D. How does Q/A work?                   | The question names the visitor concern; the response carries the minimum useful answer. It is not a repeated component shell.                                                 |
| E. How does evidence enter?             | Contextually, as an `Evidence Answer` to a named trust question, with only useful public context.                                                                             |
| F. How does evidence disappear?         | True collapse: no placeholder, empty frame, stock substitute, “coming soon” or virtue copy. Narrative continues to the next valid relation.                                   |
| G. How does consequence precede action? | Actual state and what has not happened appear before edit/recovery and before the CTA in DOM and visual hierarchy.                                                            |
| H. How does learning coexist?           | `Tôi muốn hiểu thêm` is a bounded peer continuation using the same system; it never becomes diagnosis or a second homepage product.                                           |
| I. How does mobile preserve rhythm?     | Arrival keeps choice/edit rhythm; boundary keeps clarification rhythm; consequence keeps state-first/action-second rhythm. Semantic order never changes.                      |
| J. What is forbidden?                   | Archive/paper/record identity, Q/A metronome, card grids, fake evidence, luxury/heritage color theatre, chat UI, administrative labels, decorative motion and forced novelty. |

## Composition lock

```text
ARRIVAL                 BOUNDARY                    CONSEQUENCE
question | choices      question ----> answer      dominant actual state
         | edit                       | limit      compact clarification
         v                            v            edit/recover -> action

same semantic relation; different physical grammar
```

No page may serialize the narrative into eight equal `label → heading → paragraph → cards`
sections. Adjacent roles may combine, provided their job, evidence boundary, DOM order and state
ownership remain recoverable.

## Surface/material lock

Surfaces are digital functions: canvas, reading, response, quiet, boundary, attention/action and
evidence context. They do not simulate paper, files, ledgers, wood, lacquer or “handmade” texture.
Flat continuity and changes in alignment/density carry chapters. Shadows and container chrome are
not the default grammar.

## Typography and color

- Sans-first Vietnamese typography is locked; Be Vietnam Pro remains the recommended existing
  family. Hierarchy comes from size, weight, measure, placement and rhythm. No prestige serif.
- Color is supporting, not the identity foundation: readable neutrals plus one bounded warm
  choice/focus/action relationship. Exact values remain Migration Gate-R/H6 calibration inputs.
- Meaning, boundary, error, uncertainty and state never rely on color alone.

## Evidence compatibility

The same grammar must support 0, 1 or multiple approved evidence units through contextual
insertion—not a generic gallery/grid. Adding evidence may change local density or media ratio, but
not global type, color, route, component or composition systems.

## Lane validation

Sen validates only purpose → orientation → place/people → scope/service → visit → action. Triều
validates only terminology, learning relations and review/source discipline. Removing either
corpus leaves the visual grammar intact: **PASS / PASS**.
